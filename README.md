# Learnix
This whole thing is for a school project. Learnix is designed to help users improve their knowledge on different topics.

With the app, you can create quizzes and track your progress in the statistics. This makes it easy to see your results and monitor your learning over time.

Feel free to explore the application yourself or take a look at the documentation in the `doc` folder for more information.

## Features

* Create your own quizzes
* Test your knowledge on different topics
* View your results and progress in the statistics section
* Simple and easy-to-use interface
* Unlock Achievements
* Customize UI
